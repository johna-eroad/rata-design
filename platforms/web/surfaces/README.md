# Web surfaces

## What belongs here
One file per web surface: a place users work in and return to, with no fixed start or end (for example a dashboard, map, list or settings page). Tasks with a start and an outcome are [flows](../flows/README.md). Name files with descriptive slugs, and tag each with its product segment in frontmatter.

A rule of thumb: a flow is a task with an outcome, and a surface is a place the user works in. Flows link to the surfaces they start from and return to, and surfaces link to the flows they start.
